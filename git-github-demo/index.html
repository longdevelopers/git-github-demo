Giới thiệu

Git là hệ thống quản lý phiên bản giúp theo dõi sự thay đổi của mã nguồn. GitHub là nền tảng lưu trữ mã nguồn trực tuyến, hỗ trợ làm việc nhóm, quản lý branch, pull request và theo dõi lịch sử phát triển phần mềm.

Các lệnh Git cơ bản

Quy trình làm việc

  1. Tạo repository trên GitHub.
  2. Clone repository về máy tính.
  3. Thêm hoặc chỉnh sửa mã nguồn.
  4. Commit thay đổi bằng Git.
  5. Push code lên GitHub.
  6. Tạo branch và pull request khi làm việc nhóm.
